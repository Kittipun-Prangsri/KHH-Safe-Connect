# KHH-Safe-Connect
KHH Safe-Connect เป็นระบบที่ออกแบบมาเพื่อเสริมความปลอดภัยและการเชื่อมต่อเครือข่ายภายใน (Secure Network &amp; Remote Access) สำหรับโรงพยาบาลคลองหาด (Khlong Hat Hospital - KHH) โดยมุ่งเน้นการควบคุมสิทธิ์การเข้าถึงทรัพยากรภายใน การตรวจสอบความปลอดภัยของเครือข่าย และการป้องกันภัยคุกคามทางไซเบอร์ตามมาตรฐานความปลอดภัยข้อมูลสาธารณสุข
